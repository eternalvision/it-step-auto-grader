# step-auto-grader

Небольшой browser automation script для автоматической обработки домашних работ в IT Step Academy.

Скрипт последовательно находит формы проверки домашних заданий, выбирает доступную оценку, при необходимости добавляет минимальный комментарий `good` и нажимает кнопку `Принять`.

## Что делает

- находит необработанные формы домашних работ
- ждёт, пока форма полностью загрузится и станет активной
- выбирает случайную доступную оценку
- приоритетно использует оценки в диапазоне `9-12`
- нажимает `Принять`
- если без комментария отправка недоступна, автоматически добавляет `good`
- ждёт подтверждения успешной обработки перед переходом к следующему студенту
- обрабатывает формы строго последовательно
- останавливается после нескольких подряд неудачных попыток
- выводит подробный лог в DevTools Console

## Как работает

Основной flow:

```text
find form
   ↓
wait until ready
   ↓
get available grades
   ↓
select random grade
   ↓
find "Принять"
   ↓
is button enabled?
   ├─ yes → submit
   └─ no
       ↓
     add "good"
       ↓
     wait until enabled
       ↓
     submit
       ↓
wait for UI update
   ↓
next form
```

Скрипт не отправляет все формы одновременно.

Каждая работа полностью обрабатывается перед переходом к следующей.

## Использование

1. Открой страницу проверки домашних заданий в IT Step Academy.

2. Открой DevTools.

В Chrome / Edge:

```text
F12
```

или:

```text
Cmd + Option + I
```

на macOS.

3. Перейди во вкладку `Console`.

4. Вставь содержимое `index.js`.

5. Нажми Enter.

Скрипт запускается автоматически:

```js
processAllFormsSequentially();
```

После загрузки функция также доступна глобально:

```js
window.processAllFormsSequentially;
```

Поэтому скрипт можно запустить повторно вручную:

```js
processAllFormsSequentially();
```

## Настройки

Основные параметры находятся в начале `index.js`.

```js
const MIN_GRADE = 9;
const MAX_GRADE = 12;

const AUTO_COMMENT = "good";

const MAX_WAIT_TIME = 20_000;
const MAX_WAIT_FORM_READY = 15_000;
const MAX_WAIT_ACCEPT = 5_000;
const MAX_WAIT_SUBMIT = 10_000;

const MAX_CONSECUTIVE_FAILURES = 5;
```

### Диапазон оценок

По умолчанию:

```js
const MIN_GRADE = 9;
const MAX_GRADE = 12;
```

Если среди доступных оценок есть значения в этом диапазоне, скрипт случайно выбирает одну из них.

Например:

```text
7 8 9 10 11 12
```

будет выбрана одна из:

```text
9 10 11 12
```

Если в указанном диапазоне нет ни одной доступной оценки, используется любая доступная оценка.

### Автоматический комментарий

По умолчанию:

```js
const AUTO_COMMENT = "good";
```

Комментарий добавляется только если кнопка `Принять` остаётся disabled после выбора оценки.

Можно изменить:

```js
const AUTO_COMMENT = "checked";
```

## Почему нет фиксированных задержек

Скрипт старается не полагаться на конструкции вроде:

```js
await sleep(200);
```

после действий с интерфейсом.

Вместо этого он ждёт конкретного состояния DOM:

- появления формы
- разблокировки кнопок оценок
- появления кнопки `Принять`
- разблокировки кнопки после комментария
- изменения интерфейса после submit

Это делает поведение стабильнее при разной скорости сети и Angular rendering.

## Angular Forms

Для поля комментария используется native setter:

```js
Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype, "value");
```

После изменения значения отправляются события:

```js
input;
change;
blur;
```

Это необходимо, чтобы Angular Reactive Forms корректно увидел изменение textarea.

Простой вариант:

```js
textarea.value = "good";
```

может изменить DOM, но не всегда обновляет состояние формы Angular.

## Логи

Во время работы скрипт выводит состояние в Console.

Пример:

```text
старт последовательной обработки...

поиск следующей формы (успешно: 0, ошибок: 0, подряд ошибок: 0)...

найдена форма с 12 кнопками оценок

--- студент 1 ---
выбрана оценка: 11
нажата кнопка "Принять"
✓ готов
```

Если комментарий обязателен:

```text
"Принять" disabled, пробуем автокомментарий "good"
добавлен авто-комментарий "good"
нажата кнопка "Принять"
✓ готов
```

В конце выводится статистика:

```text
=== обработка завершена ===

успешно обработано студентов: 18
пропущено: 0
ошибок: 1
```

При наличии ошибок дополнительно выводится `console.table()` с их типами.

## Защита от бесконечного цикла

Если несколько форм подряд не удаётся обработать, скрипт останавливается.

```js
const MAX_CONSECUTIVE_FAILURES = 5;
```

Это защищает от ситуации, когда интерфейс изменился или одна и та же некорректная форма постоянно возвращается как следующая.

## Селекторы

Скрипт зависит от текущей DOM-структуры IT Step Academy.

Основные селекторы:

```js
app-homework-review form[novalidate]
```

```js
mat-button-toggle button
```

```js
.mat-button-toggle-label-content
```

```js
textarea[(formcontrolname = "coment")];
```

Кнопка принятия определяется по тексту:

```text
Принять
```

Если frontend платформы изменится, эти селекторы могут потребовать обновления.

Обрати внимание на:

```text
formcontrolname="coment"
```

`coment` здесь намеренно соответствует текущему имени поля на стороне платформы.

## Ограничения

Скрипт работает напрямую с DOM текущей страницы и не использует официальный API IT Step Academy.

Поэтому:

- изменение HTML структуры может сломать селекторы
- изменение Angular-компонентов может потребовать адаптации
- скрипт должен запускаться на нужной странице
- вкладка браузера должна оставаться открытой во время обработки

## Безопасность

Перед массовой обработкой рекомендуется сначала проверить работу скрипта на нескольких формах.

Особенно после обновлений платформы.

Скрипт автоматически выставляет оценки и подтверждает домашние работы, поэтому используй его только тогда, когда автоматическая обработка соответствует твоему текущему workflow.
